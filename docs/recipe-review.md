# 料理の材料の照合結果

既存の基本料理35品の材料と分量を、文部科学省の日本食品標準成分表で確かめた結果（2026-10-10）。

## 照合に使ったもの

- **成分表2015年版 第3章「3 そう菜」**：市販そう菜41品について、複数の製造者のレシピから求めた材料配合割合（平均・最大・最小）。八訂の18群「調理済み流通食品類」のそう菜の成分値は、この配合割合をもとに計算されている。抽出したデータは `data/raw/mext-souzai-2015.json`。
- **八訂 18群の成分値**：同じ料理の100g当たりの成分値。水分の違いに左右されないよう、エネルギー100kcal当たりのたんぱく質・脂質・炭水化物・食塩で比べた。
- **八訂の重量変化率（第1章 表12）と食品の説明**：乾麺→ゆで麺の換算、ラーメンスープの使用量など。

成分表にそう菜の配合がない料理は、成分表の調理後の食品が正しく選ばれているか、換算が合っているかを確かめた。

## 直したもの

| 料理 | 見つかったこと | 直し方 |
|---|---|---|
| 肉じゃが | 牛ばら肉で作っていたため、100kcal当たりの脂質が成分表（18036）の約3.5倍。そう菜の配合では肉は赤身（もも）で、割合も少ない | そう菜13の平均配合割合で作り直し、18036 のエネルギーに合わせた（1人前 320kcal → 155kcal）。牛ばらは「入替」の候補に残した |
| きんぴらごぼう | しょうゆの割合が 9.1% で、そう菜10の範囲（1.6〜7.5%）を超えていた | しょうゆを 6g → 4.5g |
| ミートソーススパゲッティ | ゆで 220g に「乾麺80g」と書いていたが、成分表の重量変化率（220%）では乾麺100g | コメントを乾麺100gに修正（分量・栄養は変わらない） |

## 料理の追加（35品 → 77品）

- そう菜の配合割合から：白和え、ごま和え、なます、卯の花、筑前煮、南蛮漬け、ナムル、しゅうまい、中華ちまき、酢豚、八宝菜、コロッケ、クリームシチュー、ビーフシチュー、かぼちゃのスープ、コーンスープ、豆腐ハンバーグ、えびフライ、メンチカツ、えびグラタン、えびピラフ（21品）
- 成分表の料理・菓子をそのまま：とんかつ、さばの塩焼き、まぐろの刺身、ゆで卵、お好み焼き、春巻き、チャーハン、ショートケーキ、プリン、大福、ポテトチップス、チョコレート、アイスクリーム ほか
- 切り干し大根の煮物・ひじきの煮物は、市販品の配合だと煮汁が多く、材料の量が家庭の一皿とかけ離れて見えるため見送った。
- えびピラフは、そう菜の配合どおりだと食塩が八訂18014の約1.7倍になるため、食塩の量を18014に合わせた。

## 使わなかったデータベース

- **JFC-Recipe**（日本語レシピの材料を成分表に対応づけたデータセット、2026年の学会発表）：配布先と利用条件が確認できなかったため使っていない。元のレシピが投稿サイトのものなら、研究目的に限った利用条件の可能性が高い。
- **Open Food Facts**：市販品のデータで、料理の材料（配合）は持っていないため対象外。
